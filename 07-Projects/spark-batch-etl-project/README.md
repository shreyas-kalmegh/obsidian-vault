# Spark Batch ETL Project
Purpose: Build a robust batch ETL pipeline using Spark that ingests raw data from S3, processes it into curated Parquet datasets, and writes partitioned outputs for analytics.

Guidelines:
- Define clear schemas and enforce schema evolution policies.
- Use partitioning strategies that align with common query patterns.
- Implement idempotent job design and checkpointing for retries.
