## Mandatory scope policy
1. Read `CONTEXT.md` and this file first.
2. After that, open only files/directories explicitly mentioned by the user.
3. Do not run full-repo discovery by default (`rg --files`, recursive `find`, broad indexing).
4. Do not expand scope without explicit user instruction.
5. If target path is missing, ask for one specific path clarification.
