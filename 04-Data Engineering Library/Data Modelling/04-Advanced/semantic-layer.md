# Semantic Layer

## Purpose
Centralize metric definitions, dimensions, and business logic for consistent analytics.

## Key Elements
- Certified metrics
- Reusable dimensions
- Access controls and governance

## Checklist
- [ ] Metric definitions versioned
- [ ] Ownership assigned per metric domain
- [ ] BI tools integrated with one semantic contract

## Common Mistakes
- Metric logic duplicated across dashboards
- No change management for metric definitions

- How does a semantic layer reduce trust issues in BI?
