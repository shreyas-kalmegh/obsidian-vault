# Anti-Patterns

## Common Anti-Patterns
- Undefined grain
- One giant table for all analytics
- Type 2 everywhere
- No conformed dimensions
- Metric definitions duplicated per dashboard
- No backfill/replay strategy
- No ownership or lineage

## How to Respond in Interviews
For each anti-pattern, explain:
1. Why it fails
2. What signal reveals it
3. How to fix incrementally

## Checklist
- [ ] Can identify anti-pattern quickly
- [ ] Can propose pragmatic migration path
