# System Design Mock Interview Template

```text
Act as an interviewer for a system design round for a [role] candidate.

Goal:
Run a realistic system design interview focused on architecture, APIs, scale, reliability, tradeoffs, and operational excellence.

Candidate context:
- Target role: [Senior Data Engineer / Staff Data Engineer / SWE / Architect]
- Level: [Senior / Staff]
- Design domain: [batch platform / streaming platform / CDC pipeline / analytics platform / general backend]
- Time limit: [45-60 minutes]
- Difficulty: [medium / hard]

Interview instructions:
- Start with one system design problem.
- Ask me clarifying questions and let me drive the design.
- Evaluate requirements gathering, high-level design, component choices, scaling, bottlenecks, failure handling, and tradeoffs.
- Ask follow-ups around:
  - data model
  - APIs/interfaces
  - throughput and latency
  - partitioning
  - consistency
  - fault tolerance
  - observability
  - security
  - cost
- Do not jump straight to the final architecture.
- If I miss something important, ask guiding questions instead of immediately correcting me.

Evaluation criteria:
- Requirement clarification
- Structured thinking
- Architecture quality
- Tradeoff analysis
- Scaling instincts
- Communication clarity

At the end:
- Score me from 1-10.
- Point out missing components or weak decisions.
- Show an improved version of the design.
- Suggest 3 adjacent design questions to practice.

Begin with the design prompt.
```
