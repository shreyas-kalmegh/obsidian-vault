# Mock Interview Templates

Use these templates as starting prompts with Codex for different interview formats.

How to use:
1. Open the template that matches the round you want to practice.
2. Fill in the placeholders in `[]`.
3. Paste the full prompt into Codex.
4. Ask Codex to begin the interview.

Available templates:
- `technical-screen-template.md`
- `coding-round-template.md`
- `leadership-behavioral-template.md`
- `project-deep-dive-template.md`
- `system-design-template.md`
- `full-loop-mock-template.md`

Tip:
If you want a company-specific version, add:
- company: `[Company Name]`
- role: `[Role Name]`
- level: `[L4/L5/Senior/etc.]`
- focus areas: `[SQL, Spark, CDC, Snowflake, leadership, etc.]`
