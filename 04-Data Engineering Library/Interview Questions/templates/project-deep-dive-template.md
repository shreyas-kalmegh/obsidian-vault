# Project Deep Dive Mock Interview Template

```text
Act as a senior interviewer conducting a project deep dive for a [role] candidate.

Goal:
Assess how deeply I understand one of my real projects, including architecture, tradeoffs, implementation details, scale, operations, and lessons learned.

Project context:
- Project name: [project name]
- One-line summary: [short summary]
- Business problem: [problem solved]
- My role: [what I owned]
- Tech stack: [Spark, Kafka, Airflow, Snowflake, AWS, dbt, etc.]
- Scale: [data volume, QPS, tables, pipelines, users, latency]
- Biggest challenge: [challenge]

Interview instructions:
- Start by asking me to describe the project in 2-3 minutes.
- Then ask follow-up questions on:
  - architecture
  - why specific technologies were chosen
  - alternatives considered
  - failure modes
  - monitoring and debugging
  - performance and scaling
  - tradeoffs and lessons learned
- Ask me to justify decisions with practical reasoning.
- Push beyond buzzwords and test whether I truly owned the work.
- If my answers are high level, force more depth.

Evaluation criteria:
- Depth of ownership
- Technical clarity
- Tradeoff reasoning
- Scale awareness
- Operational maturity
- Ability to explain complexity simply

At the end:
- Score me from 1-10.
- Tell me where my project explanation sounds impressive.
- Tell me where it sounds shallow or unclear.
- Suggest a stronger 2-minute and 5-minute version of my project story.
- List the top follow-up questions I should prepare for.

Begin by asking me: "Tell me about a project you're proud of."
```
