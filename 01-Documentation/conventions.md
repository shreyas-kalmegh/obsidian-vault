# Vault Conventions

## Naming
- Use `topic-subtopic.md`
- Use lowercase folders
- Projects under `/07-Projects`

## Tagging
- #spark #flink #rust #python #systems #aws #streaming
- Tag flashcards with #flashcard
- Tag evergreen notes with #evergreen

## Linking
- Use [[Note Title]] for cross-linking
- Every new note must link to at least 1 existing note

## Structure
- Documentation in `01-Documentation`
- Flashcards in `09-Flashcards`
- Projects in `07-Projects`
