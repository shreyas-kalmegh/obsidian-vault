# Vault Maintenance Guide

## Weekly Maintenance
- Check for duplicate notes.
- Fix broken links.
- Add tags to untagged documents.
- Update flashcards with new insights.

## Monthly Maintenance
- Merge small notes into evergreen documents.
- Review folder hierarchy for clarity.
- Remove outdated flashcards or rewrite them.
- Re-evaluate study plan based on progress.

## Version Control
- Use Git for incremental snapshots.
- Commit once per learning session.
- Tag monthly releases of your vault.
