# Vault Workflows (Daily / Weekly / Monthly)

## Daily Workflow
1. Review yesterday’s notes.
2. Add new atomic notes (Zettelkasten).
3. Convert important insights into flashcards.
4. Link new notes to existing knowledge graph.
5. Capture tasks, ideas, and todos.

## Weekly Workflow
1. Review major topic areas (Spark, Flink, Rust, Systems).
2. Expand one deep-dive note per category.
3. Update ongoing projects with findings.
4. Clean and refactor note links.
5. Do spaced repetition on 50–100 flashcards.

## Monthly Workflow
1. Perform a structural review of folder hierarchy.
2. Archive or refactor outdated notes.
3. Add new study themes for next month.
4. Summarize long-form ideas into evergreen documents.
5. Update 6-month study plan progression.
