# 6-Month Roadmap (Summary)

See this as a tracker for the six months. Each month includes weekly tasks. Use this file to check off progress.

- Week 1: CPU & Memory basics; Rust ownership; daily Rust exercises

- Week 3: Networking basics; Python concurrency vs Rust async
- Week 4: Distributed systems primer; small local cluster test (Kafka local)

## Month 2 — Data Engineering Core
- File formats: Parquet, Avro; DuckDB experiments; Polars vs Pandas
- Rust: Polars in Rust; file IO

## Month 3 — AWS Mental Models
- S3 consistency, IAM, Lambda (Rust & Python), serverless patterns

## Month 4 — Processing Engines
- Spark internals, Flink streaming model, Arrow & vectorized execution

## Month 5 — Advanced Topics
- Iceberg/Delta, CDC concepts, Kafka semantics, Rust services

## Month 6 — Synthesis & Capstone
- Build capstone project, reorganize vault MOCs, export flashcards
