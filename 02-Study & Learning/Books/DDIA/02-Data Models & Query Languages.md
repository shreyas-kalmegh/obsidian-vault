# DDIA — Chapter 2: Data Models & Query Languages

## Summary
Covers relational, document, and graph models; schema flexibility; query languages and impedance mismatch.

## Key Points
- Relational model advantages: consistency, normalized structure.
- Document model advantages: agility & local denormalization.
- Graphs: specialized for relationships.
- Query languages arise from models — choice impacts capabilities.

## Flashcards
Front:: What trade-off does document database modeling typically make?  
Back:: Increased denormalization/duplication for simpler queries and flexibility.
